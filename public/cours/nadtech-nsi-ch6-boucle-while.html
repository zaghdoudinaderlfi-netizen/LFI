01 Pourquoi la boucle while ?

Deux outils sont déjà connus :

  • La boucle for effectue un nombre prédéfini d'itérations d'un bloc d'instructions.
  • Le branchement if exécute — ou non — un bloc selon un test effectué sur le moment.

La boucle while combine ces deux principes : elle conditionne la poursuite des itérations à un test effectué avant chaque tour.

🎯

C'est indispensable dès qu'on ne peut pas prévoir le nombre de tours : lire des saisies jusqu'à obtenir une valeur valide, chercher un élément jusqu'à le trouver, approcher un résultat jusqu'à une précision donnée.

02 Anatomie d'une boucle while

while i <= n:
    print(i)
    i = 2 * i

Trois éléments composent la construction :

  • Le mot-clef while introduit la boucle.
  • Il est suivi d'une condition appelée garde — une expression produisant une valeur booléenne.
  • Le symbole : termine l'introduction ; suit un bloc indenté, le corps de la boucle.

Le corps n'est exécuté que si la garde est évaluée à vrai. Chaque fois que le corps se termine, la garde est testée à nouveau, et le corps réexécuté tant que ces tests successifs sont vrais.

Le cycle garde → corps → garde se répète tant que la condition tient.

04 Le test vient avant chaque tour

      
Le test de poursuite est effectué avant chaque tour de boucle potentiel. Cela entraîne deux conséquences importantes :

      
    
        
  • Si le corps est exécuté n fois, alors le test est effectué n + 1 fois — le dernier test étant celui qui échoue et fait sortir.
    • 
        
  • Le corps peut n'être jamais exécuté, si le test est faux avant même la première itération.
    •

05 while ou for ?

      
Le comportement de certaines boucles while est parfaitement prévisible :

      
i = 0
while i < n:
    print(i)
    i = i + 1
print("Fin")

      
Dans ce cas, on préférera une boucle for, plus courte et sans risque d'oublier l'incrémentation :

      
for i in range(n):
    print(i)
print("Fin")


      
Attention à la variable de boucle

      
Les deux versions ne laissent pas i dans le même état à la sortie :

      
    
        
  • Avec while : après n tours, i vaut n — c'est justement ce qui cause l'arrêt.
    • 
        
  • Avec for : la variable i ne prend que les valeurs de 0 à n - 1.
    • 
      

      

        
Python

        
        

      

      
⚖️
Règle pratique : si tu sais compter les tours à l'avance, utilise for. Si l'arrêt dépend d'une condition découverte en cours de route, utilise while.

    


    
    

      
06 Divergence : quand la boucle ne s'arrête jamais

      
L'arrêt d'une boucle while est conditionné à l'échec d'un test. Il est donc possible d'écrire un programme qui ne s'arrête jamais, parce que sa condition reste éternellement vraie.

      
On parle de divergence, de non terminaison, d'un programme qui boucle ou qui part en boucle infinie.


      

        

          
          
        

        
while True:
    print("Ma quête du mouvement perpétuel progresse")

        

        
Ici l'arrêt est simulé par un bouton. Dans un vrai interprète, il faut interrompre le programme à la main (Ctrl+C).

      


      
⚠️
N'exécute pas while True sans break dans une cellule Python de cette page : elle figerait l'onglet du navigateur. Le simulateur ci-dessus est là pour ça.


      
Le piège du test d'inégalité

      
Ce programme semble anodin :

      
while i != 0:
    print(i)
    i = i - 1

      
Il ne s'arrête jamais si i est initialement négatif : en décrémentant, on s'éloigne de 0 au lieu de s'en approcher. Écrire while i > 0 aurait évité le problème.

    


    
    

      
07 Sortir d'une boucle avec break

      
La garde est évaluée avant même le premier tour. On ne peut donc pas écrire ceci pour valider une saisie — n n'existe pas encore au moment du test :

      
# Ne fonctionne pas : n n'est pas defini
while n < 0:
    n = int(input("Entrer un nombre positif ou nul : "))


      
Il faudrait dupliquer la saisie avant la boucle :

      
n = int(input("Entrer un nombre positif ou nul : "))
while n < 0:
    n = int(input("Entrer un nombre positif ou nul : "))   # duplique !

      
Ce n'est pas satisfaisant : le corps de la boucle est recopié, et toute modification devrait être faite à deux endroits.


      
L'instruction break résout le problème. Elle ne peut s'écrire qu'à l'intérieur d'une boucle et provoque son interruption immédiate :

La boucle do…while des autres langages

      
Certains langages proposent do ou do … while : la condition est examinée après chaque tour, donc le corps est toujours exécuté au moins une fois. Python n'a pas cette construction — while True + break en tient lieu.

      
// Java
public class DoWhileDemo {
    public static void main(String[] args) {
        int count = 1;
        do {
            System.out.println("Count is: " + count);
            count++;
        } while (count < 11);
    }
}

    


    
    

      
08 Chercher dans un tableau

      
Écrivons une fonction appartient(v, t) qui renvoie True si la valeur v apparaît au moins une fois dans le tableau t, et False sinon. Plusieurs solutions existent — elles ne se valent pas.


      
Compare le nombre de comparaisons effectuées par chaque version :

      

        

          
          
          
          
        


        

          
Version 1 — parcours complet (drapeau)0 comparaison

          

        

        

          
Version 2 — while paresseux (arrêt anticipé)0 comparaison

          

        

        
Le tableau contient [4, 8, 15, 16, 23, 42]. Essaie de chercher 4, puis 42, puis 99.

      


      
Version 1 — le drapeau

      
def appartient(v, t):
    trouvee = False
    for i in range(len(t)):
        if t[i] == v:
            trouvee = True
    return trouvee

      
Le défaut : le tableau est parcouru intégralement, même si la valeur est trouvée dès la première case.


      
Version 2 — while avec garde composée

      
def appartient(v, t):
    i = 0
    while i < len(t) and t[i] != v:
        i = i + 1
    return i < len(t)

      
Deux points méritent attention :

      
    
        
  • La garde contient la condition i < len(t), qui protège l'accès au tableau.
    • 
        
  • On exploite le comportement paresseux de l'opérateur and : dès que i atteint len(t), la partie gauche est fausse et t[i] != v n'est pas évaluée. Sans cela, on obtiendrait une IndexError.
    • 
      

      
À la sortie, i vaut len(t) si la valeur n'a pas été trouvée, et une valeur strictement inférieure sinon — d'où le return i < len(t).


      
Version 3 — while avec break

      
def appartient(v, t):
    i = 0
    while i < len(t):
        if t[i] == v:
            break
        i = i + 1
    return i < len(t)


      
Version 4 — return direct

      
def appartient(v, t):
    for i in range(len(t)):
        if t[i] == v:
            return True
    return False

      
La plus lisible : return sort immédiatement de la fonction, ce qui rend le drapeau inutile.

09 Terminaison et technique du variant

      
Puisqu'une boucle while peut diverger, il faut savoir justifier qu'un programme s'arrête. Considérons :

      
q = 0
while n >= 3:
    n -= 3
    q += 1
print(q)

      
La terminaison dépend de n. Or à chaque tour, la nouvelle valeur de n est strictement inférieure à la précédente. Cette valeur finira donc par devenir inférieure ou égale à 2, et la boucle s'arrêtera.


      
📉
Ce raisonnement s'appelle la technique du variant. Elle consiste à identifier une quantité — le variant de la boucle — qui est entière, positive, et qui décroît strictement à chaque tour. Une telle quantité ne peut pas décroître indéfiniment : la boucle termine forcément.


      
Trouver le variant d'une recherche

      
i = 0
while i < len(t):
    if t[i] == v:
        break
    i = i + 1

      
Ici i augmente — ce n'est donc pas le variant. Ce qui diminue à chaque tour jusqu'à s'annuler, c'est l'écart entre i et len(t). Le variant est donc len(t) - i :


      

        

          Variant = len(t) − i , avec len(t) = 6
          
          
        

        

        

        
Le variant part de 6 et décroît strictement de 1 à chaque tour. Arrivé à 0, la garde devient fausse.

      


      
Deux erreurs classiques

      
Erreur 1 — la condition d'arrêt ne permet pas de conclure. Une quantité peut décroître sans que cela suffise :

      
q = 0
while n != 3:
    n -= 3
    q += 1
print(q)

      
n décroît bien, mais la boucle ne s'arrête que si n vaut exactement 3. Si n n'est pas initialement un multiple de 3, on saute par-dessus la valeur d'arrêt et la boucle diverge.


      
Erreur 2 — la décroissance n'est pas stricte.

      
q = 0
while n >= d:
    n -= d
    q += 1
print(q)

      
Si d vaut 0, alors n ne change pas d'un tour à l'autre : la décroissance n'est pas stricte, et la boucle tourne indéfiniment.
